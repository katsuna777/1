# DemoExam2026 — авторизация обувного магазина

WinForms-приложение на .NET 8 с EF Core и MySQL, реализующее авторизацию, гостевой режим, отображение ФИО и роли, а также выход обратно к окну авторизации.

## Подключение к MySQL

Используются параметры из инструкции:

- сервер: `31.76.12.103:3306`
- база: `DemoExam2026`
- пользователь MySQL: `root`
- пароль: пустой
- таблица: `Users`
- столбцы: `Id`, `Fio`, `Login`, `Password`, `Role`

Скрипт для безопасного создания базы и таблицы: `database/init.sql`. Он не удаляет и не перезаписывает существующие данные. Роль в столбце `Role` должна точно совпадать с одним из значений: `AuthorizedClient`, `Manager`, `Administrator`.

В проекте нет исходного `user_import.xlsx`, поэтому таблица создаётся пустой. Импортируйте в неё реальные учётные записи из материалов задания.

Для сервера используйте выданную вам MySQL-учётную запись. Если она отличается от `root` без пароля, задайте переменную окружения `DEMOEXAM2026_MYSQL_CONNECTION_STRING` со строкой подключения перед запуском приложения. Не помещайте пароль в Git.

## Запуск в Windows

Откройте `DemoExam2026.csproj` в Visual Studio 2022 с установленной поддержкой .NET 8 Desktop Development либо выполните в каталоге проекта:

```powershell
dotnet restore
dotnet run
```

Перед запуском в MySQL Workbench подключитесь к серверу, выберите **File → Open SQL Script**, откройте `database/init.sql` и выполните скрипт. Требуются права на создание базы и таблиц.

Провайдер MySQL — `Pomelo.EntityFrameworkCore.MySql` версии 8.0.3, соответствующей EF Core 8.

> Учебный пример сравнивает пароль напрямую, как в исходной инструкции. Не используйте такой способ хранения паролей в реальных приложениях.
